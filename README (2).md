# 서울제일교회 주차관리앱

교인이 자기 차량을 등록하고 주차를 신청하면, 관리자(사무실·주차봉사팀)가 승인하고 구역을 배정하는 웹앱입니다.
데이터는 **구글 시트**에 저장되고, 앱 화면은 **GitHub Pages**에 올립니다. 휴대폰에서 '홈 화면에 추가'하면 앱처럼 씁니다.

## 할 수 있는 일

| 교인 (교인용 암호) | 관리자 (관리자용 암호) |
|---|---|
| 내 차량 등록·수정·삭제 | 차량번호 뒤 4자리로 차주 찾기 → 바로 전화·문자 |
| 날짜를 골라 주차 신청 (승인·대기·남은 자리 확인) | 날짜별 신청 목록, 승인·반려, 구역 배정, 안내 메모 |
| 내 신청 상태 확인, 취소 | 대기 중인 신청 한꺼번에 승인 |
| | 전체 차량 명부 관리, 연락 기록 보기 |

> 인터넷이 끊겨도 관리자 휴대폰에는 마지막으로 불러온 명부가 남아 있어 차주 찾기가 됩니다.

## 파일

- `index.html` — 앱 화면 전체 (GitHub에 올릴 파일)
- `Code.gs` — 구글 시트와 앱을 이어 주는 스크립트 (구글 시트에 붙여넣을 파일)

---

## 설치 순서 (약 20분)

### 1. 구글 시트 준비
1. 교회 구글 계정으로 [새 구글 시트](https://sheets.new)를 만들고 이름을 `서울제일교회 주차관리`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 내용을 지우고 `Code.gs` 내용을 통째로 붙여넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 고르는 칸에서 **setup**을 고르고 **실행**을 누릅니다. 권한 요청이 나오면 허용합니다.
   → 시트에 `차량`, `주차신청`, `연락기록` 탭이 생깁니다.

### 2. 암호와 정원 정하기
Apps Script 왼쪽 **⚙️ 프로젝트 설정 → 스크립트 속성 → 속성 추가**에서 세 줄을 넣습니다.

| 속성 | 값 (예) | 설명 |
|---|---|---|
| `MEMBER_KEY` | `jeil2026` | 교인용 암호. 주보·단톡방으로 알립니다 |
| `ADMIN_KEY` | (길고 어려운 암호) | 사무실·주차봉사팀만 압니다 |
| `CAPACITY` | `40` | 하루 주차 가능 대수 |

### 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**, 유형 ⚙️에서 **웹 앱** 선택
2. 실행 사용자: **나** / 액세스 권한: **모든 사용자**
3. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> `Code.gs`를 나중에 고치면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로)

### 4. 앱에 URL 넣기
`index.html`을 메모장 등으로 열어 아래 줄을 찾아 따옴표 안에 URL을 붙여넣고 저장합니다.

```js
const SCRIPT_URL = 'https://script.google.com/macros/s/여기에-붙여넣기/exec';
```

> 이 칸을 비워 두면 예시 데이터로 움직이는 **체험 모드**가 됩니다 (암호 `member` / `admin`).

### 5. GitHub Pages에 올리기
1. GitHub에서 **New repository** → 이름 예: `sjc-parking` → **Create**
2. **Add file → Upload files**로 `index.html`(과 README.md)을 올리고 **Commit**
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://(GitHub아이디).github.io/sjc-parking/` 주소가 생깁니다.

### 6. 휴대폰에 설치·안내
- 주소를 열고 **아이폰: 공유 → 홈 화면에 추가 / 안드로이드: ⋮ → 홈 화면에 추가**
- 처음 열면 **설정**에서 암호·이름·연락처를 넣습니다. 교인용 암호면 교인 화면, 관리자용 암호면 관리자 화면이 열립니다.

---

## 알아 두실 점

- **개인정보**: 교인 연락처는 GitHub에 올라가지 않고 구글 시트에만 있습니다. 앱 코드는 공개되어도 암호 없이는 데이터를 볼 수 없습니다.
  다만 교인용 암호는 여러 사람이 아는 공용 암호이고, '내 차량·내 신청'은 연락처로 구분합니다. 다른 사람의 연락처를 아는 교인이 그 사람의 신청을 볼 수 있다는 정도의 느슨한 보호이니, 교회 내부용으로 쓰시기 바랍니다.
- 교인 화면에서는 다른 교인의 연락처·명부가 보이지 않습니다. 전체 명부는 관리자 암호로만 열립니다.
- 시트에서 직접 고쳐도 됩니다 (예: 기존 차량 명부를 `차량` 탭에 붙여넣기 — ID 칸은 아무 겹치지 않는 글자면 됩니다).
- 암호를 바꾸려면 스크립트 속성만 고치면 됩니다 (재배포 불필요).
